刷入 AI Passport 电视固件

用浏览器直接写入设备，不需要安装任何软件。整个过程在这台电脑上完成，固件不会经过任何第三方服务器。

这个页面不会擦除你的设备。 它只写入固件占用的那一段地址（约 1.5 MB），设备的出厂身份信息在更靠后的位置，不在写入范围内。页面在写入前会自己核对这一点，范围不对就拒绝开始。

准备工作

  1. 用数据线把设备连到这台电脑。
  2. 确认浏览器是 Chrome 或 Edge（Safari 和 Firefox 不支持，手机浏览器也不支持）。
  3. 设备要处在可刷写状态才会出现在列表里。能正常开机时它就是这个状态；开不了机的话，按住一枚按键再开机试试。哪一枚我们没验证过，三枚都试一遍即可。

开始

刷完之后

  1. 按住电源键约 2 秒关机，再按约 0.5 秒开机。设备内置电池，拔数据线不会重启它。不做这一步，屏幕是黑的。
  2. 屏幕显示彩条和一个形如 FoloToy-XXXX 的网络名——说明它在等你配置。
  3. 到Releases 页面下载服务端，在电脑上运行。它会显示一个地址，下一步要填。
  4. 用手机连上那个网络，打开 192.168.4.1，填 WiFi 和服务器地址。
不要用其他工具对这个设备执行「整片擦除」。 esptool.py erase_flash、或者任何写着「Erase Device」「清除设备数据」的按钮，都会抹掉设备的出厂身份信息，而且找不回来。这个页面刻意不提供那个功能。
